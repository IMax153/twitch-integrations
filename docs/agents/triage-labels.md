# Triage labels

Use these strings in each issue's `Status:` line.

| Canonical role    | Tracker string    | Meaning                                        |
| ----------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue         |
| `needs-info`      | `needs-info`      | Waiting on the reporter for more information   |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                  |
| `wontfix`         | `wontfix`         | Will not be implemented                        |

When a skill asks to apply a triage role, use its tracker string.
Edit the tracker-string column to change the vocabulary.
